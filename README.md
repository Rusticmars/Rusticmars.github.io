# Personal physics website

Static site for GitHub Pages.

- index.html: overview page
- assets/: shared files (style.css for the common design, home.css and paper.css for page-specific rules, form.js for the request form)
- alscn-ferroelectrics.html, inse-bandgap-transition.html, tmd-nonlinear-optics.html, abinit-overview.html, raman-spectra-tool.html: detailed explanations of individual papers

Each paper page links to the publisher (DOI) and offers a "Request a copy" form (Web3Forms). No PDFs are hosted in this repository.

To deploy: create a repository, upload the contents of this folder to its root, then enable Pages (Settings, Pages, deploy from the main branch, root folder).
