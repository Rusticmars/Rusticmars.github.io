Raman_spec: turning ABINIT output into Raman spectra

Open-source Python software for post-processing Raman calculations from the ABINIT electronic-structure package. MIT license.

View the code on GitHub About ABINIT

In brief. A Raman spectrum is a fingerprint of how a material vibrates. ABINIT can calculate the quantities that determine it, but they arrive as raw tensors in a text file. Raman_spec reads that file and produces, for every vibrational mode, the intensity, polarization-resolved signals, and depolarization ratio, together with a broadened spectrum ready for plotting.

1. Background

In Raman spectroscopy, light scatters from a material and a small fraction loses or gains the energy of a vibration. The resulting spectrum, a set of peaks at the frequencies of the Raman-active vibrations, identifies a material and reveals its structure, strain, and defects. Predicting such spectra requires the frequencies of the vibrations and a Raman tensor for each, a 3×3 table describing how the material’s response to light changes as the atoms move (see the ABINIT page for how these are computed). ABINIT’s anaddb program writes them to a text file. Raman_spec is the next step: it converts those tensors into the quantities that can be compared with a measured spectrum.

2. What the tool does

Input. The text output of an anaddb run with the nonlinear flag enabled, plus a short plain-text input file that sets the laser energy, the temperature, the line broadening, and the output units. The laser may be specified as a wavelength (for example, 532 nm) or as an energy. No ABINIT installation is needed.

filename   anaddb.out
temp       300.0
laser_freq 532.0 nm
spread     2.0 cm-1
n_freq     400
outname    aln
relative_intensity

Output. Plain columnar text files: a broadened spectrum with the powder average and six fixed-polarization channels (XX, XY, XZ, YY, YZ, ZZ), or, with broadening switched off, one row of intensities per mode. A log file records each mode’s tensor, depolarization ratio, Raman activity, and theoretical cross-section, with a ranked list of the ten strongest modes. Nothing is plotted automatically, so any plotting tool can be used. Separate spectra are written for the transverse (TO) and each longitudinal (LO) direction.

Use. The tool runs from the command line (python Raman_spec.py raman.in) or as a Python module whose individual functions can be called directly. It requires Python 3.8 or later with NumPy and SciPy.

3. The physics

For each mode, the Raman tensor m is split into its symmetric part s = (m + mT)/2 and antisymmetric part a = (m − mT)/2, from which three rotational invariants are formed. These match the convention that ABINIT itself prints, so results can be checked against the source file:

G0 = (1/3) [Tr(m)]²,   G1 = Σij aij²,   G2 = Σij sij² − (1/3) [Tr(m)]²   (1)G0: isotropic, G1: antisymmetric, G2: symmetric anisotropic invariants; m: Raman tensor of the mode, a 3×3 matrix (dimensionless in the units anaddb writes); Tr: trace; i, j: Cartesian indices.

The powder-averaged intensity, appropriate to a polycrystalline sample or fine powder, follows from Placzek’s approximation as the sum of two scattering geometries:

I∥ = 2π P (10 G0 + 4 G2),   I⊥ = 2π P (5 G1 + 3 G2),   Ipowder = I∥ + I⊥   (2)P: prefactor defined in Eq. (3); I∥ and I⊥: intensities with parallel and perpendicular polarization of the scattered light (arbitrary units).
P = (1 / 2ωm) · (ωL − ωm)⁴ / c⁴ · [n(ωm, T) + 1]   (3)ωm: mode frequency; ωL: incident photon frequency; ωL − ωm: frequency of the Stokes-scattered photon; c: speed of light; n: Bose-Einstein occupation of the mode at temperature T (K). Evaluated in Hartree atomic units.

The depolarization ratio, ρ = I⊥/I∥ = (5G1 + 3G2) / (10G0 + 4G2), indicates how strongly a mode changes the polarization of the light: it is 0 for a purely isotropic tensor and 3/4 for a symmetric, traceless one. Each mode is then drawn as a Lorentzian line of a chosen half-width to produce the spectrum. The tool also reports a theoretical Stokes cross-section for each mode, a thermal (Einstein-oscillator) heat capacity and entropy, and, if a broadening is given, a quality factor and lifetime treating that broadening as the mode’s damping.

4. Validation

The tool was checked against an ABINIT calculation on wurtzite aluminum nitride (AlN), which has 12 modes of which 7 are Raman-active. Its invariants G0 and G2 reproduce those printed by anaddb for every active mode, to the precision of the tensors in the file. Depolarization ratios behave as theory requires: the fully symmetric A1(TO) mode at 601.26 cm−1 gives ρ = 0.7479, just below 3/4 because of its small isotropic component, and each doubly degenerate E mode gives exactly 0.7500.

The calculated frequencies lie within about 5% of the measured values, a typical level of agreement for density functional theory.

5. Limitations

The antisymmetric invariant G1 is implemented but not validated against reference data, because every tensor encountered so far has been symmetric, as non-resonant Raman tensors are. The seven intensity columns do not share one absolute scale: the factor 2π applies to the powder channel only, so powder-to-powder and channel-to-channel comparisons are meaningful but the ratio between the powder column and a single polarization column is not. Absolute cross-sections carry no empirical calibration and inherit the approximations of the underlying density-functional Raman tensor, so they are first-principles estimates. The quality factor and lifetime are only as meaningful as the broadening the user supplies. The calculation-type option is accepted but currently selects no alternative behavior, and only the text output of anaddb is read, not NetCDF files.

6. Using and citing it

The code is public under the MIT license. Work that uses it should cite ABINIT and anaddb for the underlying Raman susceptibilities, alongside the repository.
